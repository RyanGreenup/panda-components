## Keyboard Shortcuts

The application includes several keyboard shortcuts for improved navigation and accessibility:

### Layout Controls

- **`Ctrl + B`** - Toggle the sidebar/drawer
- **`Escape`** - Close the sidebar/drawer
- **`Ctrl + M`** - Toggle navbar visibility
- **`Alt + D`** - Toggle bottom dash visibility

### Sidebar Resizing (Desktop only)

- **`Ctrl + ]`** - Increase sidebar width (+100px)
- **`Ctrl + [`** - Decrease sidebar width (-100px)
- **`Ctrl + Shift + 0`** - Reset sidebar to default width (320px)

<Callout type="info">
The sidebar can also be resized by dragging the resize handle on the right edge of the sidebar (desktop only).
</Callout>
